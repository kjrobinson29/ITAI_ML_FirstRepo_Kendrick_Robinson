Welcome — this repository is a single, organized portfolio containing all course projects for ITAI-1371 (Intro to Machine Learning). How this repo is organized
- Each project directory contains:
  - README.md — problem, approach, results, learning outcomes
  - model.py or .ipynb — runnable source code (not just PDFs)
  - dataset/ — instructions for obtaining data (or small sample files)
  - results/ — saved metrics, plots, or artifacts

Getting started (quick)
1. Clone: git clone https://github.com/kjrobinson29/ITAI_ML_FirstRepo_Kendrick_Robinson.git
2. Create a virtualenv & install dependencies:
   - python -m venv venv
   - source venv/bin/activate  (or venv\Scripts\activate on Windows)
   - pip install -r requirements.txt  (or see each project README for specific deps)
3. Navigate to a project folder and run the model script:
   - python model.py
